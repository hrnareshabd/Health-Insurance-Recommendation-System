# Reporting security issues

For credentials accidentally committed or security vulnerabilities, contact
**hrnaresh39@gmail.com** privately rather than posting sensitive details in a public issue.
For ordinary bugs and methodology feedback, use GitHub Issues.

Only load model files you trained yourself or trust: Python pickle/joblib files
can execute code. Never submit private medical records or access tokens to this
public repository. This project is an educational prototype and is not a service
for processing real health records.
